# 🏓 COM7 Ping Pong League 2026

ระบบจัดการแข่งขันปิงปองภายในองค์กร COM7 ประจำปี 2026

---

## 📁 โครงสร้างโฟลเดอร์

```
com7-pingpong-league/
├── index.html          ← ไฟล์หลักของแอปพลิเคชัน (เปิดในเบราว์เซอร์ได้เลย)
├── README.md           ← ไฟล์นี้
│
├── assets/
│   └── images/         ← รูปภาพผู้เล่น, โลโก้, ไอคอนต่าง ๆ
│
├── data/               ← ไฟล์ข้อมูลสำรอง เช่น JSON export ของผู้เล่น/ผลแข่งขัน
│
└── docs/               ← เอกสารประกอบ เช่น กติกา, วิธีใช้งานระบบ
```

---

## 🚀 วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่มเติม

---

## ✨ ฟีเจอร์หลัก

- 🏆 **Leaderboard** — จัดอันดับผู้เล่นชาย/หญิงแบบ Real-time
- 📅 **Fixtures** — ตารางการแข่งขันแบ่งตามรอบ
- 🎯 **Bracket** — สายการแข่งขัน (Knockout)
- 📊 **Standings** — ตารางคะแนนรวม
- ⚙️ **Admin Panel** — เพิ่มผู้เล่น, บันทึกผล, คำนวณคะแนน

---

## 💾 การบันทึกข้อมูล

ข้อมูลทั้งหมด (ผู้เล่น + ผลแข่งขัน) ถูกบันทึกใน **LocalStorage** ของเบราว์เซอร์โดยอัตโนมัติ  
หากต้องการสำรองข้อมูล ให้ export JSON แล้วเก็บไว้ในโฟลเดอร์ `data/`
